# 完全卸载

普通的 Zotero「移除插件」会保留阅读资料、设置与本机授权，方便重新安装后继续工作。设置中「卸载与清理」用于核对这些文件，并在明确确认后一次清理所选插件资料，再移除论文伴读。

## 清理前先核对

打开入口只生成清单，不会删除文件，也不会连接模型。清单列出当前配置中可确认由插件维护的设置、加密凭据、账号记录、用量、对话、单词本，以及已登记论文文件夹中的笔记、整理文档、备份和 PDF 副本。程序会核对文件元信息、身份标识和内容校验值，不解密凭据；较大的文件在原生端分段计算校验值。

可复制清单，或逐条点击「打开位置」。默认勾选全部已确认的类别；需要留下的类别可取消勾选，界面会明确说明保留。请先另存需要的笔记或单词本，然后确认理解个人资料删除后不可撤销，并输入「完全卸载」。只有此时最终清理按钮才可点击。更改类别或重新核对清单后，必须重新确认。

执行时先暂停插件写入并等待正在保存的内容完成，再重新核对原始附件保护与文件内容。清单之外的文件不会被删除。程序按明确路径逐个处理所选文件，最后通过 Zotero 的插件管理接口移除插件，不递归删除目录，也不直接删除插件安装包。

文件在预览后发生变化时会停止，要求重新核对；未完成时不会宣称成功或提前移除插件。如果已经开始清理，插件写入会保持暂停，防止已删除的文件又被自动保存重建；可重新核对后继续。空文件夹可能保留。

## 始终保留的内容

- Zotero 文献条目、原始 PDF 附件、其他插件与 Zotero 自身的配置。
- 不能确认归属的文件、文件夹中的其他资料，以及通过符号链接指向的位置。
- 用户手动另存或导出的副本、旧版本搬迁后未登记的资料文件夹、外部浏览器的登录状态。
- 共享的 ChatGPT 网页 Cookie；如需退出网页账号，请在网页内退出。

清单会说明未能安全确认的内容。普通卸载和本机文件清理均不会替用户撤销云端服务的 API Key，也不会删除已发往服务商的对话。

## 验收清单

| 编号 | 要求 | 状态 |
| --- | --- | --- |
| U01 | 打开只读预览，显示明确文件路径、分类和保留说明 | 服务、界面单测及实际 Zotero 清单通过；长清单关闭栏固定，确认区可见且可点击 |
| U02 | 输入确认文字并明确同意清除个人资料，才能自动执行 | 实际原生按钮从禁用到完成确认后可用，类别改变须重新确认 |
| U03 | 只列可证明归属的文件；排除越界、链接和原始 PDF | 白名单、链接与附件保护单测通过；Windows 普通路径和真实合成附件保留通过 |
| U04 | 自动删除前重新核对清单，文件已修改则停止 | 实际预览后修改笔记会拒绝执行；同大小同修改时间变化及执行中变化另有故障注入测试 |
| U05 | 暂停写入，清理失败保留重试入口 | 失败不卸载、未知删除结果保持暂停、重新核对与重试故障注入通过 |
| U06 | 清理完成后通过 Zotero 管理接口卸载 | 实际卸载、完整重启及同配置重装通过，旧账号、Key、笔记和词库不会恢复 |
| U07 | 取消预览不改变现有数据、设置和登录状态 | 逐文件校验值确认取消不写入；执行中阻止关闭或重复提交；始终没有模型请求 |

本轮开发与验证仅使用合成文件和隔离配置，不执行日常配置的完全卸载。
