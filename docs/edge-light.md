# 边框追光与余辉

## 容器边界

在原有追光基础上，论文选择框、整体导航、阅读外框、用户提问气泡、输入正文框与发送区外壳均可触发局部渐变颗粒。普通按钮不作为目标；鼠标位于导航按钮附近时，可以触发外围导航容器的边线。AI 回答的每个段落不新增外框，背景与正文不染色。

遮罩复制真实四角圆角和实际计算边线宽度，支持提问气泡的不对称圆角。验证包括六类容器的四侧物理像素、曲线外侧不漏光、菜单暂停与减少动态效果。

沿边框使用 144px 平滑循环色带，保留各主题主色，向相邻冷暖辅色自然过渡。每个光斑按同一条边框坐标对齐，连续采样只叠加强弱，避免多个三色光斑平均成单色；水平和竖边使用相同规则。细碎亮点也取自同一色带，正文和背景不参与渐变。

## 交互规格

边框光效由遮罩内的局部渐变、细碎亮点与短暂余辉组成。它只改变边线区域的颜色，不填充控件背景或正文。

- 光斑直径 **72 CSS px**，约为常规鼠标指针视觉尺寸的三倍。网页无法可靠读取 Windows 指针的自定义大小，所以不声称能精确随系统指针倍率改变。
- **保留原边框的计算宽度**，只在原有边线/焦点线的遮罩内显色；72px 指沿边框的局部影响范围，不绘制填色圆。
- 局部颜色有柔和强弱渐变与细碎亮点；粒子只沿边框漂移、衰减，背景和正文不变色。
- 接触边线时有一次约 **160ms** 的柔和亮起，持续停留不反复闪烁。
- 沿边移动采样成连续轨迹，各处余辉在约 **2.5 秒**内淡出。
- 离开后，在同一边线上的短暂追踪窗口固定为 **2.5 秒**。鼠标的新位置投影到刚触碰的那一侧，让触碰高度到新高度之间也有连贯光迹；普通移动不能无限延长这个窗口。
- 切到其他控件时，旧边框自行淡出，新边框独立触发。滚动、布局明显变化、窗口失焦、关闭动效或系统减少动态效果时清理不再适合显示的轨迹。
- 设置提供明确的演示入口，不需要模型或网络，也不修改用户资料。

## 职责与资源边界

- `PCEdgeTrail`：纯数据模型，负责路径重采样、离开期限、过期和容量控制，可直接由 Node 测试。
- `PCEdgeLight`：拥有鼠标监听、目标测量、剪裁、遮罩、轨迹节点和动画清理。
- `PCTheme`：继续负责主题与动效偏好，向追光控制器传递启用状态；不直接管理轨迹。
- 总采样点最多 96 个，最多保留 8 个边框；帧请求仅合并输入和布局事件。余辉交给有限时长的浏览器动画，停止后不维持永久 JavaScript 刷新循环。
- 输入事件优先由动画帧合并；若内嵌页面节流，32ms 的一次性后备仍会更新绘制。没有输入时不会以此启动循环。
- 光效不接触会话、笔记、模型或文件格式。模型网关、问答服务和设置控制器另有明确边界，见[服务端口](responsibilities.md)。

## 验证要求

1. 纯模型验证采样连续性、跨高度的离开投影、2.5秒固定期限、过期清理、重入与容量上限。
2. 真实 Gecko 验证原边框宽度内的较大渐变/粒子范围确实产生像素差异；正文区域不发光。
3. 沿竖边快速移动再离开，检查起点、中段、终点均有光迹；离开1秒后仍有余辉，约2.5秒后消失。
4. 检查进入反馈、显式演示、快速跨控件、边框内外靠近、单侧边线、滚动裁剪、全部主题和浮窗。
5. 关闭或减少动效时立即清理节点与动画；全部到期后没有多余帧、计时器或无限增长的节点。
6. 通过核心与相关原生回归，核对源码、最终被测安装包和固定安装包一致；不把模拟模型测试描述成线上账号验证。

## 验收结果

Windows Zotero 10.0.6 验证完成：核心 **188 项**、边框粒子专项 **37 项**、界面与原生浮窗 **127 项**、单词本 **88 项**，共 **440 项通过**。

- 三主题均检测到边框颜色变化，正文采样区变化为 0。
- 在 480×820 的合成演示视口中，竖边轨迹有 275 个连续位置显色，并有多种强弱色值；这不是整块背景填色。
- 离开一秒后仍可见余辉，固定期限后粒子、计时器和绘制帧清理；继续离边移动不会无限延长期限。
- 设置演示、单侧边线、滚动裁剪、ShadowRoot 浮窗的宿主离开、销毁和减少动效均通过。
- 相同测试包逐一核对源码。测试使用合成论文与假模型响应，没有触碰日常资料，不代表其他系统、Zotero 版本或真实账号已通过。

复现方式：`python scripts/smoke_zotero.py <全新专用目录> --edge-light`，再以 `-no-remote -profile` 启动该目录生成的隔离 Zotero 配置。准备脚本需要 `reportlab`。不得使用日常配置目录。
