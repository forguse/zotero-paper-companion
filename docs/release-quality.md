## 范围与限制

- 这些检查不代表真实模型服务、跨平台、超大文库、真实读屏用户或前台帧率认证；其他系统及 Zotero 版本仍需反馈。
- 文字预读不识别扫描页和复杂图表；当前原文检索不是通用跨语言语义搜索。
- ChatGPT 套餐余量通过官方入口查询，等效美元估算不等于套餐实际扣款。
- 自动更新要求更新清单和 XPI 均可匿名下载。私有或受限下载源需要手动安装，不能借用浏览器登录或把维护者令牌写入插件。
- 完全卸载只清理明确确认、归属可核对的文件；空目录、未登记的旧迁移位置、手动导出和共享网页登录状态保留。保护逻辑不是抵抗恶意外部进程并发替换路径的原子安全认证。
- 笔记外部修改备份不是跨进程协同编辑；持续写盘失败时优先保留未保存内容。

源码、模型端口和扩展位置见[架构说明](architecture.md)与[服务端口](responsibilities.md)。测试数量不能代替真实使用反馈。
