# 单词本：收词、语境与复习

在 PDF 中划选单词，点击「加入单词本」才增加遇到次数。词库跨论文共用。卡片显示常用释义，详情保留每次遇词的论文、日期、原句、本句词义和整句译文。不同论文使用深色来源标签区分，点击可打开来源。

## 原句怎么采集

每次收词都会先在本地取句。优先利用阅读器已经显示的文字与所选位置；需要时读取所选页文字并缓存，最多保留16页。这个步骤没有模型请求，不消耗 Token。

本地无法取到可信短句时，默认出现一个不抢焦点的小提醒。在原页直接划出包含目标词一次的短句，松手后便会保存到刚才的遇词记录，不需要再次点击加入。

每个小提醒都能选择「手动补划」或「自动补采」，并切换自动补采的方式：

| 方式 | 处理的材料 | 用量 |
| --- | --- | --- |
| 手动补划 | 用户重新划出的短句 | 取句本身不调用模型；启用释义补全时再生成词义和句意 |
| 模型文字 | 选词附近的已有文字片段 | 使用翻译模型；没有文字或多个同词无法定位时提示补划 |
| OCR 图片 | 自动截取所选词附近的 PDF 图片，以红框标记选词 | 使用公式识别中选择的多模态模型；无需用户另行截图 |

设置决定默认失败处理方式，弹窗中的切换仅影响当前这次补采。可以让手动补划失败后继续由所选模型 / OCR 兜底。点击手动补划或暂不补充会停止正在进行的自动补采；如已开始的服务端请求有用量，仍以服务商记录为准。无法确定原句时保留空缺，不以模型猜测替代论文原文。补划和自动补采都不额外计数。

## 节省用量

常用释义、所选词在本句中的意思和整句译文合并生成。相同词、句子、选中位置与模型配置可复用已有结果；更换模型、推理强度或语言后不混用旧结果。手动点击「补全释义」可主动刷新。

关闭设置中的「加入时补全释义与句意」后，加入只做本地保存，自动方案也不会静默调用模型。需要时仍可点击弹窗中的「自动补采」或词条中的「补全释义」。模型不可用时，词条不会丢失，也不会换用别的模型。

## 展示与背诵

默认一行一个词，中英文同排，右侧保留个人累计遇词次数和展开箭头。「本章单词」只显示当前论文中加入的词及本篇语境；「所有单词」显示跨论文的个人完整词库，按字母排列。两处使用相同的词条结构，可搜索、展开，或进入详情；详情可查看全部论文中的来源。返回保留搜索词与位置，大量词条分页显示。独立窗口的词条和搜索框左右对齐，滚动条出现时保持展开箭头位置。

「极简」默认收起语境，每条可以单独展开；「完整」默认展开全部语境，每条仍可以单独收起。两者保留相同的英文、中文和次数首行，长内容只在各自的列中换行。重新点击「弹出单词本」会聚焦已有窗口，保留正在查看的词条和搜索词。

背诵模式先隐藏中文，点击中文区域的按钮才显示，可在同一位置重新遮住；词头始终用于打开详情。列表的展示与背诵偏好独立于复习页，返回列表后仍使用原来的偏好。

### 继续复习：浏览或自测

「继续复习」默认进入**自测**：先回想，点击「查看释义与句意」后，再选择「不会」「模糊」或「记住」。反馈保存在本机这条遇词语境上，不调用模型、不增加遇词次数。没有可信释义时不会提供掌握评分；可在「编辑与补全」手动填写或显式调用模型补全，也可切换浏览。

选择**浏览**会直接显示答案；「已复习，下一条」只推进原来的新增遇词位置，不记录掌握反馈。自测与浏览都不会在打开页面或查看答案时自动推进进度。默认七天提醒仍可在设置中按天、小时或分钟调整，也可关闭。

页面内可选择两条独立的队列：

| 队列 | 内容与进度 |
| --- | --- |
| 新增遇词 | 按遇词顺序从上次确认处继续；自测反馈或浏览确认后才推进原位置。 |
| 到期复习 | 仅显示已有自测反馈且已到期的语境；反馈不会移动新增遇词位置或重置原七天提醒。浏览时可「本次略过」，该记录仍保留到期状态。 |

下次时间采用简单固定规则：不会为10分钟后，模糊为1天后；连续选择记住依次为1、3、7、14、30、60天后，最长60天。不会或模糊会重置连续记住次数。这只是方便使用的本地安排，不是经过验证的记忆模型，也不表示长期掌握。到期队列需要主动打开，不新增高频通知；上次反馈和下次时间也会写入维护的 Markdown。

窗口启动时先显示加载提示。连接本机词库失败时可点击重试；若窗口资源未能载入，会显示恢复提示和重试/关闭按钮。更新插件后若仍停留在旧版界面，请重新启动 Zotero。

原来的新增遇词续接始终保留，不会被到期队列强行重排。也可以在本章单词或所有单词中使用背诵模式自行回看旧词。

## 加错或写错时

误点加入后，可用顶部「撤销最近加入」移除刚加入的那次记录。也可在单词详情中选择「移除此条遇词」。次数和待复习队列会同步更新；最后一条移除后，该词从正常列表隐藏。

需要找回时，展开「文件与保存位置 → 已移除记录」，点击恢复。记录的原句、日期与序号保留；原本尚未复习的记录恢复后仍待复习，已复习的记录不会重新计入。

在「编辑释义与原句」中可以更正词头，更正会应用于该词的所有语境。改成已有词时会合并记录，保留目标词已有的常用释义。修改前自动生成一份「词头更正前」JSON 备份；这些本地纠错操作不调用模型。

## 文件与占位名言

「文件与保存位置」可直接打开持续维护的 Markdown 和文件夹，也能更改位置。词库数据与原句以 `vocabulary.json` 为准；Markdown 是自动维护的可阅读文件。外部修改 Markdown 会在下次同步前备份。

### 迁移与恢复

「完整备份 .json」保存可恢复的全部主数据，包含已移除记录、释义、原句、复习位置与新增的自测反馈/下次时间；不包含插件账号或 API Key。旧备份没有自测字段时仍可导入，不会伪造历史反馈。另存的 Markdown 适合查阅，不能代替这份主数据备份。

「导入 / 恢复备份」先显示词条数、遇词数、重复、冲突和内容示例。默认合并：相同遇词 ID 不重复计数，有冲突时保留当前版本，新增记录按原顺序接入待复习队列，当前常用释义和复习位置保持。选择恢复则用备份替换整个词库和复习位置。两种方式都先另存当前 JSON，写入失败保留原状态；预览后若词库已变化，需要重新核对。

可导入本插件的完整备份或原始 `vocabulary.json`，单个文件不超过20 MB、十万条遇词。导入、备份、浏览和复习不调用模型。来源 PDF 需要在目标 Zotero 中另行同步；插件会按文献标识查找，不会用旧电脑的数字编号直接打开其他论文。

未采集到原句时，界面以淡灰色名言示例占位，标注作者和「非论文原句」。这些示例只用于显示，不写入遇词原句，也不传给模型。所选示例及核对来源：

- William Shakespeare，*Hamlet*：「Brevity is the soul of wit.」[Project Gutenberg，第二幕第二场](https://www.gutenberg.org/files/1524/1524-h/1524-h.htm)。
- Jane Austen，*Emma*：「There is no charm equal to tenderness of heart.」[Project Gutenberg，第二卷第十三章](https://www.gutenberg.org/files/158/158-h/158-h.htm)。
- Alexander Pope，*An Essay on Criticism*：「A little learning is a dangerous thing.」[Project Gutenberg，第二部分](https://www.gutenberg.org/cache/epub/7409/pg7409-images.html)。
